== 01 | an object is just a block of memory ==

A type is a set of offsets:
  sizeof(Point)      = 16
  offsetof(Point, x) = 0
  offsetof(Point, y) = 8

One type, three storage classes:
  static    (5, 7)
  stack     (2, 3)
  bss       (0, 0)

A method is a function with an explicit `this` in rdi:
  before    (2, 3)
  after     (12, -7)

An array of objects is contiguous; the loop just adds the size:
  particles[0] at byte offset 0   -> (0, 0)
  particles[1] at byte offset 16  -> (10, 20)
  particles[2] at byte offset 32  -> (20, 40)
  sum of x = 30

You pad by hand, or you pay for it:
  SpriteNaive  size=26  hp at +1  pos at +10  misaligned fields: the CPU pays on every access
  Sprite       size=32  hp at +0  pos at +8   every field naturally aligned
